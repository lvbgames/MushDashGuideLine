# Reference Sites

1. [The Game Bakers](https://www.thegamebakers.com/) — 게임 중심 구성, 게임에서 커뮤니티로 이어지는 흐름.
2. [Mega Crit](https://www.megacrit.com/) — 게임 영상·설명, Games/Community/About/Contact 구조.
3. [The Behemoth](https://www.thebehemoth.com/) — 캐릭터 중심 표현, 게임별 스토어 연결, SNS·커뮤니티.
4. [Team Cherry](https://www.teamcherry.com.au/) — 회사와 게임 상세 페이지 분리, 간결한 스튜디오 구성.
5. [Cellar Door Games](https://www.cellardoorgames.com/) — 게임별 플랫폼·출시 정보, Steam/Epic 연결 방식.
6. [Playdead](https://playdead.com/) — 영상·분위기 중심의 최소 구성.

참고 범위는 페이지 구조와 정보 위계뿐이다. 디자인, 문구, 코드, 이미지, 자산을 복제하지 않는다.
