# Documentation Router

작업 시작 시 `AGENTS.md` → 이 문서 → `CURRENT.md` 순서로 읽고, 아래 담당 문서 중 작업에 필요한 것만 선택한다.

- `CURRENT.md`: 현재 상태, 미완료 항목, 다음 작업.
- `PRODUCT.md`: 페이지 구성과 콘텐츠 우선순위.
- `CONTENT.md`: 확정 데이터·외부 링크·에셋과 콘텐츠 상태.
- `NEWS.md`: 정적 News 항목 추가·검증·공개 기준.
- `STYLE.md`: 브랜드 디자인, 반응형, 접근성 기준.
- `I18N.md`: 지원 언어, locale route, 번역 규칙.
- `LOCKED.md`: Privacy 등 변경 금지 대상.
- `VALIDATION.md`: 반복 검증 절차와 Commit·Push·배포 권한 경계.
- `DEPLOYMENT.md`: GitHub·Netlify·도메인·무료 정적 운영.
- `MAP.md` / `ARCHITECTURE.md`: 작업공간과 실행 구조.
- `REFERENCE.md`: 외부 참고 범위와 로컬 Reference.
- `DECISIONS.md`: 확정된 기술·제품 결정.
- `INVENTORY.md`: 재사용 자산·컴포넌트와 구현 순서.

같은 규칙은 담당 문서 한 곳에만 두고 다른 문서에서는 해당 문서를 참조한다.
